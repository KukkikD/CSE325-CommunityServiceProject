# CSE325-CommunityServiceProject

Community Service Project is a .NET Blazor application designed to connect community members and organizations who need help with volunteers who are willing and available to serve.

Users can post community needs, browse service opportunities, sign up to help, and find opportunities based on skills, availability, interests, and location.

## Target Users

- Community members
- Volunteers
- Schools
- Churches
- Nonprofit organizations
- Neighborhood groups

## Core Features

- Post a Community Need
- Browse Service Opportunities
- Volunteer Sign-Up
- Match by Skills
- Match by Availability
- Match by Location
- Search and Filter Opportunities
- Track Status: Open / Filled / Completed
- Volunteer Hours Tracking
- Notifications
- Organizer Dashboard
